# Phase 2 Reference: Constraint Ladder & Six Engineering Construction Operators

本细则用于阶段 2 的方案构造 Agent。锁定阶段 1 的结构性矛盾后，**禁止在单一思维框架下产出 3 个换汤不换药的变体**，必须结合「约束阶梯法」与「6 大工程构造算子」生成 **3～4 条真正正交的候选路线**。

---

## 1. 破除 AI 同质化的前置动作：约束阶梯法（Constraint Ladder）

单次生成多条方案时，大模型极易在同一个主流框架里打转（同质化效应）。先对锁定的结构性矛盾快速过三阶约束变换，强行拉开方案空间：
1. **第一阶（现实基线约束）**：保持当前工程场景的全部真实运行约束，观察现有方法在哪条约束上最先崩溃；
2. **第二阶（放松一条行业惯性假设）**：问“如果不再默认线性化 / 不再默认惯量恒定 / 不再把预测与调度拆成两阶段，数学结构会变成什么？” → 触发 `O1` / `O4`；
3. **第三阶（施加一条更严苛的实战边界）**：强加真实落地硬门槛（如单步在线求解 <100ms、100% 交流硬可行、零样本拓扑切换、连续多帧通信丢包）→ 触发 `O2` / `O5` / `O6`。

## 2. 六大工程构造算子（`O1`–`O6`）

### `O1` 打破过时假设（Assumption Breaking）
- **适用信号**：多篇文献沿用同一经典理想化前提，但在新型实际工况下该前提已产生不可忽略的偏差。
- **核心动作**：将原先被忽略或固定为常数的物理/统计机制显式写入模型核心（如决策依赖不确定性 DDU、构网/跟网混合时变惯量、时空相关极端扰动、异构通信时延与丢包、设备非线性劣化）。
- **合格判据**：用忽略该机制的旧模型直接在新工况下求解，必须产生显著的越限、失稳或经济损失（而非 <1% 的边际噪音）。
- **常见陷阱**：硬塞一个实际影响微乎其微的次要约束凑公式长度。

### `O2` 结构性破除权衡（Trade-off Breaking）
- **适用信号**：现有 SOTA 在一对核心指标间被迫妥协（求解速度 vs. 精度、鲁棒保守性 vs. 经济性、分布式隐私 vs. 全局最优性、计算复杂度 vs. 交流可行性）。
- **核心动作**：利用目标问题的特定代数/物理结构重构模型或求解流程（精确/紧致二阶锥松弛、灵敏度引导约束筛选、可行域显式投影、稀疏/对称性降维、分层分解协调），将帕累托前沿整体外移。
- **合格判据**：能从数学或物理机制上解释清楚“为何能在几乎不牺牲指标 A 的前提下显著提升指标 B”。
- **常见陷阱**：仅调多目标权重系数在原有帕累托曲线上左右滑动。

### `O3` 去障碍同构迁移（Isomorphic Transfer + Adaptation）
- **适用信号**：阶段 1 线 B 在运筹/控制/ML 顶刊找到了数学结构匹配的先进工具 `T`，但 `T` 无法直接开箱即用。
- **核心动作**：精准识别 `T` 直接套用到本领域时的 **1～2 个硬障碍**，把核心创新**锚定在“消除迁移障碍的定向改造”**上（而非“首次把工具 T 引入领域 B”）。
- **强制执行「五维结构不变量核查」**（防止被同名词汇如“稳定性/能量/图网络”误导做伪类比）：
  1. **量纲与守恒律**：潮流/能量/质量守恒等硬等式是否破坏工具 `T` 的原有前提？
  2. **时间尺度与动态时延**：工具 `T` 是否假设静态/慢变，而目标系统存在快慢时间尺度耦合或控制/通信时延？
  3. **可观测性与信息结构**：工具 `T` 是否要求全局精确状态或平滑梯度，而目标场景局部可观、含噪或非光滑？
  4. **变量空间与硬边界**：工具 `T` 是否建立在连续无约束空间，而目标问题含整数离散变量、饱和限幅或非凸硬边界？
  5. **维度扩展律**：工具 `T` 在低维成立，扩展到目标工程规模（如 118/300 节点）时复杂度是多项式还是指数爆炸？
- **合格判据**：能精确指出“不改造直接套 `T` 会在哪一行公式或哪类算例报错/发散/不可行”，且改造恰好闭合该断点。

### `O4` 割裂环节闭环耦合（Cross-Layer Coupling）
- **适用信号**：主流研究把强耦合的两阶段顺序割裂处理（预测 → 优化、规划 → 运行、快时间尺度控制 → 慢时间尺度调度、多能流/多主体独立决策），导致上游误差在下游被放大。
- **核心动作**：建立决策导向（Decision-Focused）或双向反馈耦合结构，使下游运行代价/安全边界反向塑造上游建模与学习。
- **合格判据**：两阶段割裂造成的“目标失配损失”或“不可行风险”可被显式量化且幅度显著，且闭环复杂度可控。
- **常见陷阱**：把弱耦合问题强行拼成巨型联合模型，导致求解崩溃且收益微弱。

### `O5` 机理—数据硬边界融合（Structured Physics-Data Hybrid）
- **适用信号**：纯机理模型难以刻画复杂未知非线性或在线求解太慢，纯数据驱动方法在分布外失稳且无法保证硬物理安全。
- **核心动作**：明确切割分工——**物理模型负责硬约束边界、拓扑不变性与主趋势骨架**；**数据驱动负责未知残差拟合、非凸代理映射或求解器热启动**；两者通过可微优化层、安全过滤层（CBF/QP 投影）或解析残差结构实现**硬耦合**。
- **合格判据**：消融物理骨架（退化为纯黑箱）或消融数据模块（退化为纯机理）时，各自暴露清晰可测的性能或安全退化。
- **常见陷阱**：只把物理量拼进神经网络输入层，或在 Loss 里加软罚项假装满足硬约束。

### `O6` 极端失效点外科手术（Failure-Mode Redesign）
- **适用信号**：近 2 年最强 SOTA 在常规场景表现优异，但在明确存在的恶劣/边界工况下系统性崩溃（不可行、振荡、超时、样本外漂移退化）。
- **核心动作**：理论定位或仿真复现崩溃条件，对失效环节实施定点重构，保证“常规工况不退化、崩溃工况稳定挽救”。
- **合格判据**：崩溃工况必须是工程界高关注的真实风险场景，而非生造的无意义数学角落。

## 3. 伪创新一票否决红线（自查即毙，严禁提交至阶段 3）

| 红线类型 | 典型症状 | 处置方式 |
| :--- | :--- | :--- |
| **换壳缝合怪** | `LSTM → Transformer/Mamba`、`PSO → 新动物群算法`、`DQN → 较新 RL` 却讲不出目标问题特有的结构因果 | 直接毙掉 |
| **无耦合拼接** | 模块 A 抄论文 1、模块 B 抄论文 2，两模块无数学传递关系，拆开各自独立也能跑 | 直接毙掉 |
| **造词遮羞布** | 核心卖点全靠生造晦涩缩写或华丽框架名，还原成行业通用术语后本质仍是常规调参 | 直接毙掉 |
| **不可消融/不可证伪** | 无法定义逐模块消融变体，或说不清去掉某模块后到底哪个具体指标会恶化 | 直接毙掉 |
| **回避强朴素基线** | 只敢拿 10 年前老旧方法做靶子，不敢直面“把近期 SOTA 微调 10 行代码”的直观解法 | 退回重写或毙掉 |

## 4. 正交性与门控要求

在 `ideation/02_candidate_proposals.md` 中输出的 3～4 个候选方案（`P1`–`P4`）必须满足：
1. **严格引用阶段 1 矛盾编号**：每个方案标明所针对的 `C_x`（必须存在于 `01_assumption_failure_matrix.md`）；若融合了用户初始「人类种子思路」，明确标明来源；
2. **路线真正正交（反同质化）**：至少覆盖 **2 种以上不同构造算子**，且至少包含 1 条**反向路线**（从与 `P1` 相反的技术哲学出发，例如 `P1` 走解析数学重构、`P2` 走物理—数据硬融合或机制假设重构）；
3. **区分性预测前置**：每个方案必须提前写清“哪类可观测指标能把本方案与强朴素基线明确区分开，以及什么实测结果会直接证伪本方案”；
4. **门控校验**：落盘后立即运行：
   ```bash
   python scripts/ideation_ctl.py check --dir ideation --gate 1
   ```
   校验通过后，方可启动阶段 3 独立红队子智能体。
